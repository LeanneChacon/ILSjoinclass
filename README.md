Upload `index.html` and `intercambio_join_class_student_graphic.jpg` to the `main` branch.

Then go to:
Repository → Settings → Pages → Build and deployment → Deploy from a branch

Choose:
- Branch: `main`
- Folder: `/ (root)`

Save. Your public page should be:
https://leannechacon.github.io/ILSjoinclass/
